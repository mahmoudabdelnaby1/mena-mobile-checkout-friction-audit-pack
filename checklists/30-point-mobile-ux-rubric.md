# 30-Point Mobile UX Audit Rubric
- [ ] 1. Mobile viewport uses `width=device-width, initial-scale=1.0`.
- [ ] 2. Touch targets on payment methods are >= 48px in height.
- [ ] 3. Tabby / Tamara installment breakdown displayed dynamically below price.
- [ ] 4. Phone input defaults to regional country flag (+966 / +20).
- [ ] 5. One-click Apple Pay button appears above standard form fields.
